## Описание проекта
Анализ исторических данных о финансировании стартапов для оценки перспектив венчурных инвестиций и прогнозирования доходности. 

## Навыки и инструменты
* Python
* Pandas
* Matplotlib
* Seaborn

## Общий вывод
Анализ показал, что основная доля капитала концентрируется в небольшом числе компаний с длительным циклом финансирования, а наиболее устойчивые тренды роста и возврата средств демонстрируют private equity и debt financing.
