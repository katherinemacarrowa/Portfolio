## Описание проекта
Анализ ключевых параметров (расположение, меню, формат, ценовая политика) более 8000 заведений общественного питания Москвы и формирование рекомендация для инвестиционного фонда.

## Навыки и инструменты
* python
* pandas
* matplotlib
* seaborn
* phik

## Общий вывод
* Доминируют кафе и рестораны (52,6 %) — рынок ориентирован на «место для времяпрепровождения».
* ЦАО — главный концентратор: в нём почти в 2,5 раза больше заведений, чем на севере; средний чек ≈ 1200 руб. По мере удаления от центра чек снижается (до ~720 руб.).
* Рынок преимущественно несетевой (61,88 %), но сети сильны в сегментах с фокусом на скорость и стабильность (кофейни, пиццерии, булочные).
* Размер зала зависит от концепции: рестораны и бары — медиана ~80 мест; форматы с высокой оборачиваемостью — ~50–65 мест.
* Рейтинг слабо зависит от формата: большинство категорий удерживают оценку выше 4,0; преимущество даёт качество исполнения, а не выбор сегмента.
* Цена коррелирует с качеством: высокий чек — фильтр качества и стабильности; в низких ценовых сегментах — максимальная неоднородность.
* Северо‑Западный АО (4,9 %) — потенциальная зона роста при подтверждении трафика и спроса.
