## Описание проекта
Изучение изменений в пользовательском спросе сервиса Яндекс Афиши: сработал фактор сезонности, и пользователи поменяли предпочтения или изменилась аудитория. Разбираемся, какие события стали привлекать больше зрителей, а какие организаторы и площадки выбились в лидеры. 

## Навыки и инструменты
* python
* pandas
* matplotlib
* seaborn

## Общий вывод
| Категория | Вывод | Данные/Метрика |
| :--- | :--- | :--- |
| **Общая динамика** | Рост числа заказов к осени | Июнь: 34 тыс. → Октябрь: 99 тыс. заказов |
| **Структура спроса** | Смещение в сторону спорта и театра; снижение доли концертов | Рост доли «0+», снижение доли «18+» |
| **Средний чек** | Падение среднего чека в дорогих категориях | Концерты: −12%, Театр: −18%, Ёлки: −15% |
| **Пользовательская активность** | Ритм: будни > выходные & осень > лето| - |
| **Мобильные vs Десктоп** | Мобильные пользователи активнее (не отвергается) | Заказов на человека: 11.8 против 4.6 |
| **Интервал между заказами** | Мобильные покупают чаще (не отвергается) | Интервал: 20.7 дней (моб) против 24.0 дней (десктоп) |
| **Регионы-лидеры** | Сильная концентрация в 2 регионах | Каменевский регион — 27% мероприятий; Североярская область |
| **Партнёры-лидеры** | Топ-5 партнёров генерируют основную выручку | 65% выручки приходится на 5 партнёров («Билеты без проблем», «Мой билет», «Облачко» и др.) |
