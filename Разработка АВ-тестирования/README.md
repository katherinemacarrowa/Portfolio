## Описание проекта
* A/B-тестирование нового алгоритма рекомендаций для развлекательного приложения с «бесконечной» лентой коротких видео. 
* Гипотеза: новый алгоритм рекомендаций показывает пользователям более интересный контент, что должно привести к росту доли успешных первых сессий.
* Ключевая метрика — доля успешных первых сессий (пользователь возвращается в приложение после первого знакомства с лентой).
* Метод проверки — Z-тест для пропорций, односторонняя альтернатива (доля в тестовой группе B выше контрольной A), уровень значимости 0,05.

## Навыки и инструменты 
* Python
* Pandas

* Расчёт параметров А/В-теста
* Статистический анализ

## Общий вывод
Новый алгоритм рекомендаций не привёл к росту ключевой метрики. Доля успешных первых сессий в тестовой группе оказалась незначимо ниже контрольной (разница −0,11 п. п.). P-value составило 0,578, что многократно превышает порог 0,05, — нулевая гипотеза об отсутствии различий не отвергается. Наблюдаемая разница объясняется естественным разбросом данных, а не эффектом алгоритма.
